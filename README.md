# Network Analysis

## Project Overview

This project focuses on analyzing network traffic and understanding how communication occurs between systems.

## Objective

The objective of this project is to understand packet flow, network protocols, source and destination IP addresses, ports, and basic network communication.

## Tool Used

* Wireshark

## What I Did

* Captured and analyzed network packets.
* Identified common network protocols.
* Analyzed source and destination IP addresses.
* Observed TCP and UDP traffic.
* Examined port numbers used by different services.
* Studied how packets move between a client and server.

## Key Learning

Through this project, I gained practical understanding of network traffic analysis and how protocols are used during communication between systems.

## Skills Demonstrated

* Networking Fundamentals
* Packet Analysis
* TCP/IP
* Network Protocols
* Wireshark
* Basic Cybersecurity Analysis
